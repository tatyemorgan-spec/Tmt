# Best daily workflow: dialler

Built from Antoinette's TASKS note (28 Sep), her training call, and the SOPs.
Her rules: **check tasks + new VSL leads first thing · new leads and booked calls first · tasks cleared every day.**

## Before 9am: set up (15–20 min, can be done from your phone)
1. **Slack #1-new-apps:** any overnight apps? Claim with ✅.
2. For each one you can't call right now: send **Tye — Acknowledgement: New App** (or **Acknowledgement: Booked Call** if they booked), then set a Close task for **9am**.
3. **Close inbox:** look at today's tasks. Note which have a set time (usually only a handful, e.g. 4 of her 22).
4. **Freeman's calendar:** any calls today? Has each one had a confirmation, watched the videos, and got a "Notes for Freeman"?
5. Run `/queue` for your ordered list, then `/prep` on the first 3.

## 9:00–10:30: call block 1 (speed to lead)
1. **New VSL leads not contacted yet.** **Booked calls / New Opportunities first.**
2. Anyone with a Freeman call today: morning check-in (text *or* call, not both).
3. After every call: `/log` (note + status + text in one go).

## 10:30–12:30: booked calls + timed tasks
- Booked leads you haven't qualified yet: qualify, send the videos, confirm or cancel (protect the diary).
- Any tasks with a set time.
- Write "Notes for Freeman" for today's and tomorrow's calls (`/freeman-notes`).

## Midday (30 min): admin
- Close: every call has a note, the status is right, and opportunities are right (booked = opportunity with a date, no-show = New Deal Lost).
- Airtable: update the outcome, revenue and cash rows (`/log` tells you what to set).

## 13:00–16:00: call block 2 (untimed tasks)
Order: **New Opportunities → VSL follow-ups (FU1/2/3) → "watched the videos?" check-ins → under-£5k leads → webinar leads → no-shows → nurture.**
- Under £5k is lower priority but still gets called, because £3k+ can do Management.
- 3 contacts over about 3 days and no reply → NGMI (last text leaves the door open).

## Around Freeman's calls
- ~15 min before: **Tye — Reminder: Few Minutes**.
- Straight after: did they show? No-show → **No Show Rebook** text + call, New Deal Lost, Setter Pipeline, task in 2 weeks. Showed → ask Freeman the outcome and update Close + Airtable.

## 17:00–19:00: call block 3 (people finishing work)
- Second attempts on anyone you missed in the morning. 9–5 workers answer now.
- Good slot for **webinar discovery video calls**.

## End of day (15 min)
- **Every task cleared.** Done, or rescheduled with a date. Never left overdue (Close tasks sometimes vanish, so double-check).
- `/eod`: report for Freeman + Slack draft.
- Tomorrow: any bookings that need a "call tomorrow" reminder? Send it now.

## Weekly rhythm
- **Friday:** anyone booked for Monday gets videos to watch over the weekend. Monday morning, check in.
- **Friday:** `/weekly` report + `/objections`.
- Anyone booked a week+ out: a touchpoint every 2–3 days (Trustpilot, a testimonial matched to them, "excited for your call?").

## When you're at uni / your other job
- Keep Slack notifications on for #1-new-apps.
- Can't call? Acknowledgement text within minutes, then a task for your next free slot. Speed to lead still counts: they feel seen, and other mentors are hitting them too.

## After Freeman's call: payment follow-through (added 5 Oct)
Freeman leaves a CRM summary note with the agreed plan, payment date and next steps. Your job is to get it over the line:
1. Same day: text "How'd the call go?", pass on anything Freeman asked you to, send proof (student video + Trustpilot).
2. Send the payment link (WhatsApp if SMS fails) and agree a **specific** pay-by date and time.
3. Close task for that date/time: "confirm instalment paid". Call, don't just text.
4. Once paid: lead → Signed Up - Balance Owed, opportunity → Signed Up (won) with the value, Airtable Cash Collected, add to earnings/commission.csv. Book their first 1:1 and invite them to the next in-person event.
5. If the date slips: one call + one text, then flag to Freeman. Never offer a different plan or discount yourself.

## Logging rule
Call Assistant now writes call summaries, but statuses, opportunities and tasks don't update themselves. After every real conversation, set the status, set the next task with a time, and add a two-line note (outcome + next step).
