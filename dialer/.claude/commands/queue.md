1. **Callbacks** — incomplete tasks/call tasks assigned to me, due today or overdue (find_tasks, is_complete=false). Plus logs/calls.csv rows with callback_date = today.

Never include DNC, DQ, NGMI, Signed Up, Refunds, Withdrawn.
Output one table per bucket: name · phone · reason/last touch · cheat line (one line: the hook to open with). If a brief exists in briefs/ use its cheat sheet line.
End with: total count vs today's dial target.
