# How to edit these templates in Canva

1. Open Canva → **Create a design** → search "Instagram Post" (or
   "Instagram Story" for the story template, "Portrait" 1080×1350 for
   carousel slides).
2. In the left sidebar, click **Uploads → Upload files**, select the
   `.svg` file you want to use.
3. Drag the uploaded SVG onto the blank canvas — it will snap to fill
   the page since the sizes already match.
4. Double-click any placeholder text (the parts in `[brackets]`) to
   edit it — Canva treats each text element as separately editable.
5. To swap colors: click a shape, use the color picker in the top bar,
   and paste in the hex codes from this pack's README so every graphic
   in a set stays consistent.
6. To swap fonts: select any text box → font dropdown → search for a
   close Canva-native match (e.g. "Playfair Display" or "Bebas Neue"
   for the display font, "Inter" or "Lato" for body text).
7. **Download → PNG** (or JPG) when done, sized for the platform you're
   posting to.

Total time from upload to finished post: usually under 5 minutes once
you've done it once.
