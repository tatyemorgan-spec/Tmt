# Social Media Template Pack (Canva-ready)

Six editable social graphic templates for local service businesses:
quote post, before/after, story promo, carousel cover, carousel tip
slide, and a testimonial post. Same brand system as `../../site-builder`
(dark/near-black base, one green accent, serif display + sans body) so
these match any site this repo generates for a client — a business
gets a matching website *and* social kit.

## Honest scope note

Canva's `.canva` project format is proprietary and only editable inside
Canva's own app — there is no way to generate one outside Canva, by
Canva design (every "Canva template" seller on Etsy hits this same
wall). What *is* portable, and what this pack ships, is real **SVG**
files: fully editable vector graphics at the exact dimensions Canva/
Instagram use, with placeholder text already laid out. Canva imports
SVGs directly (`Uploads → Upload files`), and once uploaded you can
double-click any text/shape to edit it like a native Canva element.
That gets a buyer to "edit in Canva" in under 60 seconds — see
`marketing/canva-import-guide.md`.

## Customizing

Every template uses the same two colors and two fonts, set once at the
top of each file — find/replace across all six:

- `#17181c` — ink/near-black
- `#2f6f4f` / `#9fd8b8` — brand accent (dark/light variants)
- `#f7f6f3` — paper/background
- Fonts: `Georgia, 'Times New Roman', serif` (display) and
  `Helvetica, Arial, sans-serif` (body/labels) — swap for the client's
  actual brand fonts (see `site-builder`'s "Bold Statement" pairing —
  Bebas Neue + Inter — for a client that wants the exact site-builder
  look).
