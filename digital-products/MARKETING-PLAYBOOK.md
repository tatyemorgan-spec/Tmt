# Marketing Playbook — 7 Digital Products

Built from the "Top 7 AI digital products to sell in 2026" reference
videos. Every product below is a real, tested deliverable in this
folder — not a mockup. This playbook is the launch + monetization
layer on top of them.

## Which one to start with

You don't need to launch all 7 at once. Pick based on what you already
have:

- **No audience yet, want proof fast** → start with #3 (AI Prompt
  Pack) or #4 (Social Templates). Cheapest to make, cheapest to buy,
  fastest to validate that people will pay you at all.
- **Already do local-business web work** (this repo's `site-builder`)
  → start with #6 (Mini Course) to sell the *skill*, then #1/#3/#4 as
  upsells to your existing client-services business.
- **Comfortable getting on calls / already have some audience** →
  start with #5 (Coaching), it has the highest revenue per sale by far.
- **Want passive, no-calls income** → #1, #2, #3, #4 are all
  fire-and-forget once listed.

## Bundling (this is where the real money is)

Individual $9–$29 products are a volume game. A bundle sells for more
per buyer with almost no extra work:

- **"Local Business Starter Bundle"** — #1 (Life OS) + #3 (Prompt
  Pack) + #4 (Social Templates) — $49 (vs. $40 bought separately,
  priced *up* because "bundle" signals completeness, not because it's
  a discount).
- **"Start a Web Design Side Hustle"** — #6 (Mini Course) is the
  spine; #1 to manage clients, #3/#4 to deliver client marketing —
  $79 for all four.
- **Coaching (#5) as the top of the funnel** — sell #1/#3/#4/#6 cheap,
  then invite buyers to a free discovery call for #5's higher-ticket
  offer. This is the single highest-leverage move in this whole
  playbook: low-price products build the list, coaching monetizes it.

## Platform setup checklist (do this once)

- [ ] **Gumroad** account — fastest to list, handles file delivery,
      takes ~10% fee. Best default for #1–#4, #6, #7's starter kit.
- [ ] **Etsy** account (optional, adds search traffic) — best for #1,
      #3, #4 (buyers already search "notion template"/"canva template"
      there). Etsy takes listing fees + ~6.5% transaction fee.
- [ ] A **link-in-bio** page (Linktree, or a one-page site built with
      `../site-builder` itself) pointing to every product.
- [ ] One **email capture** point (even a free Mailchimp/ConvertKit
      tier) — every product's landing page/PDF should funnel here so a
      $9 buyer today can be marketed the $47 course next month.

## 14-day launch calendar (one creator, all 7 products)

| Day | Action |
|---|---|
| 1 | List #3 (Prompt Pack) and #4 (Social Templates) on Gumroad — cheapest to finish, fastest proof of concept |
| 2–3 | Post Script 1 + 2 from each product's `marketing/launch-scripts.md` (4 posts) |
| 4 | List #1 (Life OS) after building it in Notion per its README |
| 5–6 | Post Life OS scripts; start replying "LIFEOS"/"PROMPTS" comments with the DM templates |
| 7 | List #2 (Budget Tracker) and #6 (Mini Course) |
| 8–9 | Post scripts for both; announce the Local Business Starter Bundle |
| 10 | Set up #5's coaching landing page live (deploy `05-online-coaching-offer/site/`) |
| 11–12 | Post coaching scripts; open discovery-call booking |
| 13 | Decide on #7: launch the POD store for real, or list the starter kit |
| 14 | Review what sold, double down on the 1–2 products with the best reply/sales rate — cut or reprice the rest |

## What "getting paid" actually requires (outside this repo)

This repo produces the products and the copy. Two things need to
happen on your side, in real accounts, before money moves:

1. **A place to take payment** — Gumroad/Etsy handle this for
   products #1–#4, #6, #7's kit. For #5 (coaching) and #7 (live
   store), you need a Stripe account (coaching) and a
   Shopify/Printful pairing (merch) — both are free to start.
2. **Consistent posting** — every `marketing/launch-scripts.md` file
   is written to be posted, not just read. The products don't sell
   themselves; the 14-day calendar above is the minimum cadence to
   find out which ones will.
